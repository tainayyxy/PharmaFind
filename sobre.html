SOBRE NÓS

Comparar preços pode ser mais simples.

A PharmaFind é um projeto acadêmico desenvolvido com o objetivo de demonstrar uma experiência efetiva para consulta e comparação de preços de medicamentos.

PROPÓSITO

Simplificar

Centralizar a consulta em uma interface clara para reduzir o esforço necessário na comparação de diferentes opções.

PROTÓTIPO

Começar pequeno

A primeira versão utiliza dez medicamentos demonstrativos, permitindo validar o fluxo antes de desenvolver uma estrutura maior.

FUTURO

Evoluir

Em uma versão futura, o projeto utilizará dados reais, APIs, banco de dados e preços atualizados diretamente de diversas farmácias.

Por que existimos?

Nascida para resolver uma dor real.

O preço de um mesmo medicamento pode variar muito de uma farmácia para outra, e a maioria das pessoas paga esse valor sem saber que existia uma opção mais barata a poucos passos de distância.

O PharmaFind nasceu para acabar com essa incerteza: comparar preços entre farmácias antes da compra, de forma simples e imediata, para que ninguém pague mais do que precisa por um medicamento.
